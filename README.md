# Arcadia — единый лаунчер для всех игр

Собирает игры со всех лаунчеров и папок в одну библиотеку с обложками, коллекциями и учётом времени. Работает в **Windows 10/11** и **Linux** (с версии 2.1).

С версии 2.0 Arcadia написана на **Rust + Tauri** вместо Electron: интерфейс рисует системный WebView2 (он уже есть в Windows 10/11), а не встроенный Chromium. Программа весит ~8 МБ вместо ~90 МБ, в простое занимает примерно в 3–4 раза меньше памяти и запускается быстрее. Библиотека, настройки и обложки из 1.x подхватываются как есть; заново нужно только войти в аккаунты Epic/GOG (ключи теперь шифруются иначе).

## Что умеет

**Источники игр (находятся автоматически)**
| Источник | Как находит | Как запускает |
|---|---|---|
| Steam | все библиотеки Steam (`libraryfolders.vdf`), время из профиля Steam | `steam://rungameid/…` |
| Epic Games | манифесты `ProgramData\Epic\…\Manifests` | через Epic Games Launcher |
| GOG Galaxy | реестр GOG | напрямую exe (без Galaxy) |
| EA app | реестр + `__Installer\installerdata.xml` | exe игры (EA app подхватится сам) |
| Ubisoft Connect | реестр Ubisoft | `uplay://launch/…` |
| Battle.net | реестр установленных игр Blizzard | `Battle.net.exe --exec="launch КОД"` |
| BattleState (Tarkov, Arena) | реестр Battlestate Games | открывает BsgLauncher, время считает по папке игры |
| Папки / торренты / репаки | каждая подпапка указанной папки — игра | найденный exe |
| Вручную | кнопка «Добавить игру» или перетаскивание .exe / .lnk / .url / папки в окно | |

Для игр из папок Arcadia сама выбирает главный .exe (отбрасывает установщики, `unins000`, redist, crash-handler'ы) и чистит названия: `Cyberpunk.2077.v2.1-FitGirl` → «Cyberpunk 2077», `Ведьмак 3 [R.G. Механики]` → «Ведьмак 3». Нераспакованные репаки (где есть только setup.exe) пропускаются.

**Библиотека**
- Сетка обложек, поиск (Ctrl+F), сортировка, размер обложек, фильтры по лаунчерам
- Избранное, недавние, скрытые игры, блок «Продолжить играть»
- Коллекции: создайте и перетаскивайте игры на название коллекции слева (или правый клик по обложке)
- Страница игры: баннер, описание, жанры, время, сессии
- Правка: своё название, свой exe и аргументы запуска, своя обложка/баннер (файл или ссылка), повторный поиск обложки

**Обложки и описания** — автоматически: из кэша Steam → магазина Steam (без ключа) → SteamGridDB (если указать бесплатный ключ в настройках, нужен для игр, которых нет в Steam).

**Учёт времени** — игра считается запущенной, пока работает любой процесс из её папки. Поэтому время учитывается и для игр, запущенных через Steam/Epic/Battle.net, и (по желанию) для игр, запущенных вообще не через Arcadia. Для Steam-игр показывается большее из времени Steam и Arcadia. Раздел «Статистика»: топ игр, активность за 2 недели, время по лаунчерам.

**Статус, теги, фильтры, вид списком**
- Статус игры: «Играю», «Хочу пройти», «Пройдено», «Брошено» — на странице игры или правым кликом; на обложке видна цветная метка.
- Свои теги («кооп», «на вечер»…) — «Изменить → Теги». Кнопка фильтра в заголовке раздела: отбор по статусу, жанрам из магазина и своим тегам. Поиск ищет и по тегам.
- Переключатель «Обложки / Список»: таблица с наигранным временем, статусом и временем прохождения.
- Большая библиотека: при изменениях перерисовываются только изменившиеся карточки, а обложки за пределами экрана не отрисовываются.

**«Во что поиграть?»** — кнопка с кубиком сверху: случайная игра из установленных, из «Хочу пройти», из давно не запускавшихся или из текущего раздела.

**Сколько проходить** — на странице игры время прохождения с HowLongToBeat (сюжет, сюжет + доп., 100%) и сколько осталось с учётом наигранного. Ищется само при первом открытии; если сайт сменил формат или игра не нашлась — «Указать вручную».

**Несколько способов запуска** — «Изменить → Способы запуска»: профили «С модами», «DX11», другой exe или ссылка `steam://…` со своими аргументами. Выбор — стрелкой у кнопки «Играть» или в контекстном меню; любой профиль можно сделать основным.

**Действия перед запуском** — «Изменить → Перед запуском»: включить/выключить zapret или VPN, схема питания «Высокая производительность», запустить программу до игры и после выхода. После выхода из игры всё возвращается как было.

**Время из Epic и GOG** — время из аккаунта Epic (после входа) и из базы GOG Galaxy подхватывается так же, как у Steam: показывается большее из времени лаунчера и Arcadia.

**Discord «Играет в …»** — для игр не из Steam (торренты, Tarkov, игры из папок). Discord показывает статус от имени приложения, поэтому один раз создайте его: discord.com/developers → New Application → назовите «Arcadia» → вставьте Application ID в «Настройки → Интеграции».

**Режим для геймпада и ТВ** — кнопка с геймпадом, F10 или Start на геймпаде: полноэкранный интерфейс с крупными обложками. Стик/крестовина — выбор, A — играть, X — в избранное, Y — случайная, B — выход.

**Уведомления Windows** — загрузка в Steam завершена, торрент скачан, новые бесплатные игры Epic, скидки из списка желаемого Steam, VPN упал/переподключился, стратегия zapret подобрана. Каждое отключается в «Настройки → Уведомления».

**Загрузки торрентов** — через веб-интерфейс qBittorrent («Настройки → Интеграции»): прогресс, скорость и оставшееся время в разделе «Загрузки». Если торрент сохраняется в папку из «Настройки → Библиотека», после загрузки игра сама появляется в библиотеке.

**Мониторинг железа и оверлей в игре** — раздел «Мониторинг».
- Windows: модуль скачивается по кнопке (~8 МБ) в `%APPDATA%\Arcadia\modules\monitor` — LibreHardwareMonitor (датчики) и PresentMon от Intel (FPS). Температуры, загрузка, частоты, мощность и вентиляторы процессора, видеокарты, памяти и дисков с графиками. Запуск датчиков один раз спрашивает права администратора; переключатель «Без запроса UAC» создаёт задачу в планировщике Windows, и дальше датчики включаются без окна UAC (в том числе сами при запуске игры).
- Linux: датчики читаются напрямую из системы (hwmon, amdgpu, nvidia-smi, /proc) — ставить ничего не нужно, прав администратора тоже.
- **Оверлей в игре**: прозрачная панель поверх игры — FPS, время кадра, 1% low, загрузка и температура CPU/GPU, видеопамять, память, время сессии, часы. Состав, угол экрана, размер и прозрачность настраиваются; показывается сам при запуске игры и прячется после выхода, переключается горячей клавишей (по умолчанию Shift+F12). В игру ничего не внедряется (FPS считается по событиям Windows через PresentMon), поэтому оверлей безопасен с античитами — BattlEye, EAC, Vanguard. Виден в оконном режиме и в «полноэкранном без рамки» (так работают почти все современные игры); в эксклюзивном полноэкранном режиме игра его перекрывает — переключите её на «без рамки».
- В Linux показатели прямо внутри игры рисует **MangoHud** (Vulkan, OpenGL, DXVK/VKD3D под Wine/Proton) — для игр, которые запускает Arcadia, включается одним переключателем с теми же настройками. Для игр Steam добавьте в параметры запуска `mangohud %command%`, в Heroic и Lutris есть свой переключатель MangoHud.

**Трей и автозапуск** — сворачивание в трей при закрытии, недавние/избранные игры в меню трея, запуск вместе с Windows (свёрнутым), глобальная горячая клавиша (по умолчанию Ctrl+Alt+G), сворачивание окна при запуске игры.

## Магазины и аккаунты (необязательно)

Раздел «Магазины и аккаунты» в левом меню.

**Вход в аккаунт** — по желанию, к каждому лаунчеру отдельно:
- **Steam, Epic Games, GOG** — после входа в библиотеке появляются все купленные игры, включая неустановленные (раздел «Не установлены»). Кнопка «Установить» передаёт игру официальному клиенту (`steam://install/…`, Epic Games Launcher, GOG Galaxy) — он скачивает её, и после установки игра становится обычной.
- Для Steam можно не вводить пароль: «Аккаунт … из клиента» берёт аккаунт, в который вы вошли в Steam (нужен открытый список игр в профиле). Для скрытого профиля — вход или Steam Web API ключ.
- Вход идёт в окне официального сайта; Arcadia не видит пароль. Ключи доступа Epic и GOG шифруются средствами Windows (DPAPI). «Выйти» удаляет вход и cookies сайта.
- **EA app, Ubisoft Connect, Battle.net, BattleState** не дают сторонним программам список купленных игр. Для них — вход на сайте (для страниц магазина) и кнопка «Открыть лаунчер».

**Встроенный браузер** (страницы магазинов, профиль, друзья, список желаемого, скидки):
- ничего не загружается, пока не нажата «Включить браузерный режим»;
- одновременно живёт только одна страница, «новые вкладки» открываются на её месте;
- процесс страницы полностью уничтожается при скрытии окна в трей, через 1 минуту после сворачивания и через 30 секунд после ухода из раздела (настраивается) — и загружается снова, только когда раздел опять на экране;
- блокировка рекламы и трекеров, «экономный режим»: без видео и трейлеров, без автовоспроизведения и WebGL;
- в панели видно, сколько памяти занимает страница и сколько запросов заблокировано;
- кнопки «Установить» / «Играть» на страницах магазина открывают официальный лаунчер.

- кнопка «На весь экран» (или F11) разворачивает страницу на весь экран, Esc — обратно.

Настройки: «Настройки → Браузер».

**Установленные и неустановленные игры.** В каждом разделе, где есть и те и другие, игры разделены на две группы, а переключатель «Все / Установлены / Не установлены» в заголовке оставляет только нужные. «Настройки → Поведение → Скрыть неустановленные игры» убирает их из библиотеки совсем.

**Прогресс загрузки (Steam).** Пока Steam скачивает или обновляет игру, на обложке и странице игры видно процент, скачанный объём, скорость и оставшееся время; все загрузки — в разделе «Загрузки», а в подсказке значка в трее — проценты. Arcadia читает это из файлов `appmanifest` Steam, поэтому прогресс виден, даже если загрузку начали в самом Steam. Когда игра скачалась, она сама становится установленной. Epic Games и GOG Galaxy не сообщают прогресс другим программам, поэтому для них его нет.

## Обход блокировок: zapret и VPN

Кнопка «Zapret · VPN» в верхней панели, пункт «Обход блокировок» слева или меню в трее.

**Zapret** — управляет вашей сборкой zapret для Windows (например, [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube/releases)):
- укажите папку (или «Найти автоматически» — ищет на Рабочем столе, в Загрузках, в корне дисков);
- выберите стратегию из списка (`general.bat`, `general (ALT).bat`…) и нажмите кнопку включения;
- winws.exe запускается скрыто, без чёрного окна консоли; Windows спросит права администратора;
- «Игровой фильтр» — обход и для игровых портов 1024–65535;
- можно включать вместе с Arcadia; при выключении удаляется и драйвер WinDivert;
- **«Подобрать автоматически»**: Arcadia по очереди включает каждую стратегию (один запрос прав администратора на всю проверку), проверяет YouTube и Discord и оставляет лучшую.

**VPN** — на ядре [sing-box](https://github.com/SagerNet/sing-box) (скачивается в один клик или укажите свой `sing-box.exe`):
- вставьте свои ссылки `vless://` (включая Reality), `vmess://`, `trojan://`, `ss://`, `hy2://`, `tuic://`, ссылку на подписку `https://…` или JSON sing-box;
- выбор сервера или «Автовыбор» (самый быстрый), проверка пинга, обновление подписок;
- режим «Системный прокси» (без прав администратора: браузеры и большинство программ) или «Весь трафик (TUN)»;
- российские сайты (.ru/.su/.рф) напрямую, игры из библиотеки напрямую (в TUN — чтобы не рос пинг);
- при выходе из Arcadia системный прокси всегда возвращается как было;
- **автообновление подписок** по расписанию (6 / 12 / 24 ч);
- **аварийный выключатель**: если ядро VPN упало, системный прокси остаётся на «мёртвом» порту — трафик не уходит напрямую, а Arcadia переподключается (5 попыток). Не вышло — блокировка снимается и приходит уведомление. Работает в режиме системного прокси; в TUN без VPN трафик и так не идёт;
- **выбор программ** (режим TUN): «все программы», «только выбранные» или «все, кроме выбранных».

Серверы с транспортом **xhttp** работают через второе ядро [Xray](https://github.com/XTLS/Xray-core): оно тоже скачивается в один клик и нужно только если такие серверы есть. sing-box при этом остаётся главным (TUN, маршрутизация, автовыбор), а xhttp-серверы подключает через локальный SOCKS-порт Xray.

Не поддерживаются подписки в формате Clash/YAML.
Журнал VPN: `%APPDATA%\Arcadia\vpn\core.log`.

## Linux

Что работает так же, как в Windows: библиотека и учёт времени, обложки, коллекции, статусы, профили запуска, HowLongToBeat, Discord-статус, уведомления, qBittorrent, VPN, мониторинг и оверлей, режим для геймпада.

- **Источники**: Steam (обычный, Flatpak, Snap), Heroic Games Launcher (Epic, GOG, Amazon — с временем игры из Heroic), Lutris, папки с играми. В папках находятся и родные для Linux игры (`.x86_64`, `.sh`, AppImage, исполняемые файлы), и Windows-игры (`.exe`).
- **Windows-игры с торрентов** запускаются через Wine, Proton (umu-run) или свою команду (например, `gamescope -f -- wine`) — «Настройки → Linux», там же префикс Wine. Время считается и для игр под Wine/Proton.
- **Купленные игры** Epic и GOG ставятся через Heroic (кнопка «Установить» открывает его).
- **VPN**: Arcadia скачивает ядра sing-box и Xray для Linux; системный прокси выставляется в GNOME и KDE. Для режима TUN один раз спрашивается пароль — ядру выдаётся право управлять сетью (`setcap`).
- **Zapret**: используется [zapret от bol-van](https://github.com/bol-van/zapret), установленный как служба (`sudo ./install_easy.sh` → `/opt/zapret`); Arcadia включает и выключает её (пароль через polkit). Стратегия задаётся в `/opt/zapret/config`, подбирается `blockcheck.sh`.
- **Схема питания** перед игрой — power-profiles-daemon («performance»).
- **Страницы магазинов** открываются отдельным окном (встроить их в окно Arcadia WebKitGTK не позволяет).
- Глобальные горячие клавиши работают в X11; в Wayland — зависит от окружения.

Установка: `sudo apt install ./arcadia_2.1.0_amd64.deb` (Debian, Ubuntu, Mint) или `Arcadia-2.1.0-x86_64.AppImage` — сделайте файл исполняемым и запустите (любой дистрибутив). Нужны WebKitGTK 4.1 и GTK 3 — они есть в любом современном дистрибутиве. Данные хранятся в `~/.config/Arcadia`.

## Установка (Windows)

- `Arcadia-Setup-2.1.0.exe` — установщик (ставится для текущего пользователя, без прав администратора; ярлыки в меню «Пуск» и на рабочем столе, удаление через «Приложения»).
- `Arcadia-Portable-2.1.0.zip` — портативная версия: распакуйте в любую папку и запустите `Arcadia.exe`. Данные всё равно хранятся в `%APPDATA%\Arcadia`.

Нужен WebView2 Runtime — он встроен в Windows 11 и обновлённую Windows 10; если его нет, установщик скачает его сам. Windows SmartScreen может предупредить, что приложение без цифровой подписи — «Подробнее» → «Выполнить в любом случае».

## Сборка из исходников

Нужны [Rust](https://rustup.rs) (stable) и [Node.js](https://nodejs.org) 20+ (только для Tauri CLI).

На Windows:
```
npm install
npm run dev          # запуск с отладкой
npm run build        # установщик в src-tauri\target\release\bundle\nsis
```
На Linux нужны ещё `libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev`; `npx tauri build --bundles deb,appimage` → `.deb` и AppImage в `src-tauri/target/release/bundle`.
Из Linux для Windows (кросс-сборка через mingw): `./build-windows.sh` → `dist/Arcadia-Setup-*.exe` и `dist/Arcadia-Portable-*.zip`.
Выпуски собирает GitHub Actions (`.github/workflows/release.yml`): метка `v*` → сборки для Windows и Linux и страница выпуска с файлами.
Тесты: `cd src-tauri && cargo test`.

## Где хранятся данные

`%APPDATA%\Arcadia\` (Linux: `~/.config/Arcadia/`) — `library.json` (библиотека, время, коллекции, настройки; рядом резервная копия `.bak`), `media\` (обложки), `web\` (вход на сайтах магазинов), `vpn\`, `modules\` (модуль мониторинга), `arcadia.log` (журнал).

## Структура

```
src-tauri/src/lib.rs          запуск, плагины, трей
src-tauri/src/app.rs          окно, состояние, фоновые циклы (учёт времени, загрузки, сеть)
src-tauri/src/commands.rs     все команды интерфейса
src-tauri/src/scanners/       steam, epic, registry (GOG/EA/Ubisoft/Battle.net/BattleState), linux (Heroic, Lutris), folders, manual, gog_time
src-tauri/src/accounts/       steam, epic, gog — вход и купленные игры
src-tauri/src/net/            zapret, vpn (sing-box + Xray), links (разбор ссылок)
src-tauri/src/browser.rs      встроенный браузер магазинов с выгрузкой страниц
src-tauri/src/actions.rs      действия перед запуском, уведомления, расписания
src-tauri/src/extras.rs       HowLongToBeat, автоподбор zapret, новости магазинов, qBittorrent, мониторинг
```

## Ограничения

- Epic Games и GOG Galaxy не сообщают прогресс загрузки другим программам — он есть только для Steam.
- HowLongToBeat не даёт официального API: если сайт поменяет формат, поиск перестанет работать до обновления Arcadia (ручной ввод остаётся).
- Discord-статус требует своё приложение в Discord Developer Portal (одна минута, см. выше).
- Часть датчиков (процессор, материнская плата) LibreHardwareMonitor видит только с правами администратора.
- Встроенный браузер магазинов на Tauri — дочернее окно WebView2; если страница встанет не на своё место после смены масштаба Windows, переключите раздел.
- Оверлей Arcadia не виден в играх в эксклюзивном полноэкранном режиме (в Windows) и поверх полноэкранных игр в Linux — там его роль выполняет MangoHud.
- FPS в Windows считает PresentMon: нужен модуль мониторинга и запущенные датчики. Без модуля оверлей показывает загрузку процессора, память и видеокарту NVIDIA.

## Если игра не нашлась или запускается не тот exe

- Правый клик → «Изменить» → «Свой файл»: укажите нужный exe и аргументы.
- Игра из лаунчера, которого нет в списке, — перетащите её .exe или ярлык в окно.
- Добавьте папку в «Настройки → Библиотека», если игры лежат на другом диске.
